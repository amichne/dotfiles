# Agent guidance catalog

Dotfiles owns personal writing preferences and this local entry point.
Slopsentral owns development standards, task selection, detailed procedures,
and validators. File presence alone does not activate guidance in a harness.

## Select the work

| Intended action | Read before acting |
| --- | --- |
| Produce or revise original prose | [Writing](writing.md); preserve requested formats and literal text |
| Design, change, or review software | Slopsentral [global instructions](https://raw.githubusercontent.com/amichne/slopsentral/refs/heads/main/docs/public/reference/global-instructions.mdx), then its [task catalog](https://raw.githubusercontent.com/amichne/slopsentral/refs/heads/main/source/CATALOG.md) |
| Prepare dotfiles source changes or change installed HOME configuration | [Repository instructions](../../docs/repository-instructions.md), in addition to the applicable shared procedure |

Global instructions take precedence over other development guidance. Select the
procedure for the intended action, then read its detailed references when their
conditions apply. Reuse verified reads at a consistent revision. Reconsider the
selection when the action changes.

Use a verified installed Slopsentral resource when available; otherwise read its
canonical source. An offline snapshot must identify its revision and any gap
against current authority. Disclose unavailable sources. Do not install or update
a package merely to read guidance.

[B0](B0.md) is an optional compact reminder. The
[baseline guide](../../docs/engineering-baseline.md) explains native integration
and evidence requirements. Keep detailed standards with their Slopsentral owners.
