# Engineering baseline

Dotfiles keeps the short B0 source at `.config/agent-engineering/B0.md`.
B0 states shared engineering rules for types, effects, evidence, and focused tests.
It is plain guidance without a runtime or automatic enforcement.

Native instructions and hooks remain private.
Dotfiles does not install B0 into Codex or Pi instruction files.
Keep each project's rules in that project's instruction files.

[Slopsentral](https://github.com/amichne/slopsentral) owns the optional skills and validators.
Use a project's explicit commands for its necessary checks.
Use `./scripts/check.sh` for the dotfiles repository.
